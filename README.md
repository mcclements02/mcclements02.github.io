# mcclements02.github.io

Portfolio site for Matthew Clements: Principal Solution Architect and AI product engineer.

Live at **https://mcclements02.github.io**

A single hand-written `index.html` with inline CSS and a few lines of JS. No framework, no build step and no trackers. Images live in `assets/`.

## Edit and preview

```bash
python3 -m http.server 4321 --directory .
```

Then open http://localhost:4321. Pushing to `main` redeploys through GitHub Pages.
