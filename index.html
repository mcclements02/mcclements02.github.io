01

Sango Sports Lab Live on the App Store

An AI coach that isn't trusted with the measurement.

Record a phone clip of an athlete's rep (a jump, a sprint, a swing) and get a graded performance report with drills to fix what it found. The hard part: a language model will happily call a squat “excellent” with no idea how deep it was. So the pipeline is built so the model supplies judgment and language, and the geometry supplies the truth.

  1. Step 1The phone measures

    Apple Vision extracts a 17-joint pose and the ball trajectory on-device. A kinematic extractor turns that into joint angles, rep windows and tempo.

  2. Step 2The cloud interprets

    Gemini receives the clip and the measured features, then grades six performance metrics.

  3. Step 3The measurement wins

    Model scores are clamped to within ±3 of the on-device engine, so results stay reproducible and explainable.

Engineering worth a look

  • Shadow evaluation. A TypeScript shadow engine and a 2D-vs-3D pose comparator run beside production and log drift, with no way to change a user's score.
  • Dark launches. Every ML component is tagged live, dark or dormant. Gated features turn on through Remote Config without an app release.
  • One entitlement, two stores. Apple IAP (server-side JWS verification) and Stripe resolve into one billing state. A web subscription unlocks iOS, and removed team seats are revoked cleanly.
  • Models named by role. scoring-current and text-current are aliases in one config file, so moving the whole product to a new model is a one-file change.
  • Rules tested, not assumed. Firestore and Storage rules run against the emulator suite. App Check protects the clients, and every credential lives in Secret Manager.

02

offEarth In daily use · iOS & macOS

A large language model that runs entirely on a phone.

No account, no server, and it works in airplane mode. Conversations never leave the device. A cloud app can throw hardware at a problem. On a phone you live inside a fixed memory ceiling, a thermal budget and a battery, and every design decision trades off between those three.

0.03stime to first token on a follow-up turn, down from 0.56s, by reusing the KV cache
8Ktoken context on a phone. Flash attention with a q8_0 KV cache halves KV memory.
2,870automated tests across iOS and macOS, zero failures
0servers that can read your data. Sync is end-to-end encrypted.

Engineering worth a look

  • Surviving jetsam. iOS kills apps that exceed their memory allowance, without warning. A resource governor sizes the context window from the device's RAM tier, the per-process ceiling and each model's real weights, read from its GGUF header. KV cost per token varies 4.6× across the 20-model catalog.
  • Not cooking the phone. A PI controller paces prefill against a thermal setpoint. It runs at full speed while there's headroom and eases off before iOS throttles the CPU.
  • Sync with no trusted server. Devices pair by QR code with X25519 key agreement, HKDF subkeys and ChaCha20-Poly1305. Conversation state is a CRDT ordered by hybrid logical clocks. Devices talk over Multipeer on the same network and through a stateless zero-knowledge relay otherwise.
  • Ahead of upstream. I vendored and re-pinned the llama.cpp Swift wrapper to support new model architectures, and fixed a recurrent-state reset that crashed the next decode on Qwen 3.5's linear-attention layers.
  • Phone → Mac dispatch. You can send a coding task to an agent on your Mac. It is scoped to one authorized folder through a shadow git directory that writes nothing into that folder.

Honest status: not on the App Store yet, because content filtering and an age rating for AI chat are still outstanding. Android is a tested core port, not a shipping app.

Approach

How I build with AI, and how I don't.

The same principles run through every project above. They also make AI systems something an enterprise customer can trust.

01

Ground the model in measurement.

LLMs supply judgment and language, and deterministic signals supply the numbers. Sango clamps model scores to on-device geometry. AbleScan writes fixes from the page's actual HTML and caches them by issue fingerprint.

02

Ship dark, promote on evidence.

Features land behind remote flags, and shadow evaluators measure them against production before promotion. The trading agent can't touch a funded account until its own paper record clears the bar.

03

Write down what's true.

Status maps tag every component live, dark or dormant. READMEs include honest-status sections, threat models and caveats, so what's missing is listed rather than hidden.

04

Treat agents like a team.

I build with several AI coding agents in parallel (Claude Code, Codex, Gemini). I also wrote the tooling that keeps their work from colliding: a shared-ledger protocol and a quorum where one writes and the others review.
